# 에어허브 (Air Hub)

전국 17개 시/도 칩을 클릭하면 실시간 미세먼지 농도·등급·예보·건강 행동요령을 확인할 수 있는 반응형 웹 서비스입니다. (`air_hub_PRD.md` 기준 v1.0 구현)

## 시작하기

1. 의존성 설치
   ```bash
   npm install
   ```
2. 환경변수 설정
   ```bash
   cp .env.local.example .env.local
   ```
   `.env.local`을 열어 공공데이터포털(data.go.kr)에서 발급받은 에어코리아 서비스키(Decoding 키)를 `AIRKOREA_SERVICE_KEY`에 입력합니다.
3. 개발 서버 실행
   ```bash
   npm run dev
   ```
   브라우저에서 http://localhost:3000 접속

## 주요 기능

- 17개 시/도 칩 리스트 (즐겨찾기 최대 5개, `localStorage` 저장)
- PM10 / PM2.5 실시간 농도 + 통합대기환경등급 배지 (색상 + 텍스트 병기)
- 오늘/내일/모레 대기질 예보
- 등급별 건강 행동요령
- 서버 사이드 캐시(메모리 + 파일, TTL 10분)로 공공데이터 API 일 호출 제한(500회) 대응
- API 실패 시 마지막 성공 데이터 + "갱신 지연 중" 표시, 캐시조차 없으면 에러 UI + 재시도 버튼
- 360px ~ 1920px 반응형 레이아웃

## 참고

- 서비스키는 서버(API Route)에서만 사용되며 프론트엔드에 노출되지 않습니다.
- `.env.local`을 설정하지 않으면 API가 명확한 설정 오류 메시지를 반환하며, 프론트는 에러 UI + 재시도 버튼을 정상적으로 표시합니다.
